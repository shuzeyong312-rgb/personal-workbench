## 2026-10-29 独立 Code Review 修复

依据 [ChatGPT 对 38cb84f 的审查评论](https://github.com/shuzeyong312-rgb/personal-workbench/issues/8#issuecomment-6491463289)，该基线为 BLOCKED；以下为待新 SHA 独立复审的修复，不冒称审查项已独立关闭。

- **P1-1**：新产品不再仅凭批次公司是否为空判定来源。批次公司为空、有效资料索引能确定唯一公司时，以该公司填充首录资料公司兼容字段；一个工作簿可按产品分别确定不同公司。已显式填写的批次资料归属公司仍用于新产品兼容字段，不改写已有产品的首录公司。
- **同一产品的原文归属**：有效资料索引只有一家公司时使用该公司；有多家公司时，批次资料公司须明确匹配其中一家，否则整组待处理，不按行序选择。页面显示归属及候选，支持“放弃选择并返回上传”，保留文件后重新预览。不同产品的多公司候选无法由同一批次选择满足时，可明确跳过尚未确定的产品组，分别选择归属后再次预览。
- **P1-2**：有显式资料索引时，仍为主行全文保存独立来源记录，保留参数、卖点、价格备注等输入；显式来源原有短摘录、文件名及页码不改。全文记录只确认公司和整理工作簿，不推断厂家原件名、页码或日期。显式来源已经含完全相同全文时复用，避免重复。保留产品时不可单独跳过全文保存记录；整组跳过仍可用。
- 新预览/回执添加 `import_plan_version=2`，使旧 V2 ready 预览返回 `preview_rule_changed`。历史 committed 回执按原决策摘要查询与重放，不受该门禁影响；身份版本和数据库 Schema 不变。

三个最小复现先在原代码失败，再由修复转绿。新增 9 项隔离回归覆盖单一明确公司、跨产品混合公司、同产品多公司决策、主行原文保留、禁止跳过全文、旧预览/回执兼容、写失败完整回滚及全文精确复用。隔离后端全量 **889 项通过**；其后新增两项也通过，最终 V2 专项 **40 项通过**。前端 **226 项通过**，typecheck/build 通过；另有临时库真实 API 的浏览器操作验证，不新增前端 E2E。
