# 1688 经营指标增量 POC

## 1. 目的与边界

日期：2026-10-09。

本轮只评估月成交、上架时间、平台标签三个字段能否进入后续正式 Spec。复用 [1688 销量数据源验证](1688-sales-source-validation.md) 的 5 个 active 商品及其失败证据；不访问平台、不改数据库、Collector、API、Frontend 或正式测试，也不保存或提交凭据、Cookie、Token、headers 或原始响应。

`Go` 表示字段来源、粒度、口径、稳定性和访问条件已有足够证据，可以进入字段级正式 Spec；`Partial` 表示有真实观察但仍缺关键合同证据；`No-Go` 表示目前没有足够依据进入正式 Spec。`No-Go` 不代表平台没有该字段。

## 2. 本轮核查与环境门槛

- 已阅读协作方式、竞争情报重构计划、竞品分析基准、既有销量来源验证和根目录 `poc_sales_validation.py`。
- 既有 POC 使用本机 Chrome、项目 `.browser-profile` 和已安装扩展，最多从本地 SQLite 只读取 5 个 active 商品，以真实页面响应监听 `mtop.1688.pc.plugin.od.data.query`；脚本只在内存解析响应，不保存完整响应。
- 当前 `.browser-profile` 和扩展目录存在；本机有 Chrome 进程，但没有 9222 CDP 监听会话。无法确认这些进程是否使用 POC 档案，也无法确认登录态。扩展来源/授权条件未在仓库证据中确认。
- 因进程归属、登录态与合法访问条件均未建立，本轮不启动第二个 POC 浏览器实例、不打开商品 URL、不发请求。故无新增样本、无重复读取，也不把环境阻塞伪装成平台字段缺失。

## 5. 来源与脚本审查结论

1. 既有销量值来自扩展相关的网络响应，而非已验证的 1688 官方公开交易数据源。扩展响应只证明当时捕获到这些原始值；不证明它是权威成交账本、完整覆盖或口径准确。
2. `poc_sales_validation.py` 用页面 URL 选择商品并监听目标响应，但没有校验响应载荷中的 Offer ID 与当前 URL 一致；跨商品归属仍缺直接证据。脚本还会将商品 URL 和 Offer ID 写入终端 JSON 输出。本轮没有运行脚本，因此没有产生这类输出或新响应。
3. 既有报告表明 `totalSales`、`totalOrder` 的语义不同或至少不稳定；`saleQuantityList` 记录稀疏且日期缺口多，不能替代月成交口径，也不能推导每日销量。
4. 竞品基准中的 SaaS 页面列标题（如“月销件数”“上架时间”）是功能展示参考，页面示例数据不是本项目字段来源、接口许可、准确率或覆盖率证据。
5. 本轮没有尝试第三方 SaaS、未授权接口、验证码绕过或登录态读取；不把插件数据直接称为可信交易数据。

## 6. 是否进入正式 Spec

**暂不建议启动经营指标正式 Spec。** 月成交为 Partial，上架时间和平台标签为 No-Go；三者都缺少可复核的当前来源/访问授权与重复观察。该结论只阻塞新经营指标产品化，不影响已有价格、MOQ、SKU 等事实位置工作。

后续若重新开展 POC，先满足以下门槛，再用原有 5 个商品重复采集并覆盖原来 2 个未触发样本：

1. 确认使用的浏览器扩展和数据源有合法授权，且用户提供/确认可用的本机登录会话；不得读取、导出或提交凭据。
2. 对每个响应核验 offerId 与目标页面一致；对未触发、登录、验证、扩展不可用分别记录原因；失败值保持未采集。
3. 对同一商品做至少两次独立观察并覆盖不同时间点；记录原始值、响应时间、重复一致性和字段可见性。重复值只能说明相同观察，不代表成交增长或交易真值。
4. 月成交需有来源定义说明商品/店铺粒度、件数/订单数/代销含义、窗口边界、刷新频率及档位边界；档位在业务允许前始终保留原文，若定义仍不清则不得精确排名。
5. 上架时间需确认其对应的商品事件（首次发布或当前链接发布）和日期精度；标签需取得原始名称、归属粒度、状态有效时间，并证明采集失败不会被解释为标签取消。

上述门槛通过后再逐字段重判 Go/Partial/No-Go；不要求三个字段捆绑通过，也不为未通过字段先建数据库、API 或 UI。

## 7. 未验证问题

- 当前本机 1688 登录态、用户账号可访问范围、扩展数据源提供方及其授权范围。
- `last30DaysSales` 是否对应商品件数、订单数或代销，以及窗口、时区、缓存和刷新语义。
- 原响应是否有可校验的 Offer 身份，及同一商品重复请求是否稳定。
- 上架时间和平台标签在原始页面、官方可用来源或获授权扩展中的真实位置、字段名和覆盖率。
- 字段在下架商品、登录过期、验证页、未触发插件请求时的行为。
