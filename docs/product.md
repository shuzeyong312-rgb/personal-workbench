# Personal Workbench

## 1. 产品定位

Personal Workbench 是一个仅供个人使用的 Web 工作台，用来把工作中反复出现的问题逐步软件化、工具化。

长期可能承载自动上架、选品、竞品监控等工具，但当前 V1 只做一件事：

> 1688 竞品监控。

V1 完成并稳定运行之前，不扩展其他业务模块。

## 2. V1 目标

建立一个可长期使用的 1688 竞品监控闭环：

1. 手动添加 1688 商品链接；
2. 将商品加入竞品组；
3. 每天自动采集一次商品数据；
4. 保存每日快照；
5. 对比前后变化；
6. 在 Web 工作台展示今日发生变化的竞品；
7. 查看 7 天 / 30 天趋势。

## 3. V1 核心功能

### 3.1 竞品管理

- 手动粘贴 1688 商品链接；
- 支持创建竞品组；
- 商品可加入指定竞品组；
- 支持查看已监控商品。

### 3.2 每日采集

目标采集字段：

- 商品标题；
- 店铺名称；
- 当前价格；
- SKU；
- SKU ID；
- SKU 当前库存；
- 销量 / 成交数据；
- 主图；
- 商品状态；
- 采集时间。

每天采集一次，并保存为历史快照。

### 3.3 变化识别

系统需要识别：

- 涨价 / 降价；
- 销量增加；
- SKU 新增 / 减少；
- SKU 库存变化；
- 商品下架；
- 标题变化；
- 主图变化。

### 3.4 趋势

支持查看：

- 近 7 天趋势；
- 近 30 天趋势。

长期趋势以本系统每天保存的快照为准，不依赖外部平台长期保存历史数据。

### 3.5 首页

首页 V1 的核心内容：

> 今日发生变化的竞品。

优先展示真正发生变化的商品，而不是堆砌大量静态数据。

## 4. 当前已验证的采集能力

技术 POC 已确认：

- 使用 Playwright + 本机 Chrome；
- 使用独立浏览器 Profile 保存 1688 登录状态；
- 商品详情页 HTML / 内嵌数据可以提取：
  - offerId；
  - 商品标题；
  - 店铺名称；
  - 当前价格；
  - SKU 名称；
  - skuId；
  - SKU 库存 canBookCount；
- 1688 官方采购助手相关网络接口可以提取：
  - 近 30 天销量；
  - 累计销量；
  - 累计订单；
  - 销量历史；
  - 价格历史。

采集实现应优先读取结构化 HTML / 内嵌 JSON / Network Response，DOM 文本作为兜底，不以模拟人工点击作为主要采集方式。

## 5. V1 明确不做

当前不做：

- AI 分析；
- 自动选品；
- 自动上架；
- 多用户；
- 权限系统；
- 邮件 / 微信 / 桌面消息推送；
- 云端部署；
- 复杂爬虫架构；
- 代理池；
- 多 Agent 编排；
- 其他电商平台。

这些需求可以记录，但不得阻塞或扩大 V1。

## 6. V1 完成标准

满足以下条件才认为 V1 完成：

- 可以手动添加并管理 1688 竞品；
- 可以按竞品组管理商品；
- 可以复用登录状态完成每日采集；
- 核心商品数据可以稳定保存；
- 可以保存每日历史快照；
- 可以识别主要变化；
- 首页可以展示今日发生变化的竞品；
- 可以查看 7 天 / 30 天趋势；
- 单个商品采集失败不会导致整个任务中断；
- 采集失败有明确状态和错误记录；
- 连续运行一段时间后数据仍然可追溯、可解释。

## 7. Assumptions

当前暂按以下前提设计：

- 仅一名用户，即项目作者本人；
- 运行环境主要是个人 Windows 电脑；
- 电脑在计划采集时间处于可运行状态；
- 1688 登录状态可以通过浏览器 Profile 复用；
- V1 监控数量属于个人工作规模，不需要分布式采集；
- 每天采集一次已经满足当前业务需求。

## 8. Unknowns

以下问题仍需在正式实现过程中继续验证：

- 主图变化最稳定的识别方式；
- 商品下架 / 失效的统一判定规则；
- 官方采购助手接口长期稳定性；
- 登录状态失效后的处理方式；
- 1688 页面结构变化时的兼容策略；
- “销量”在不同商品页面中的具体口径是否始终一致。

这些 Unknown 不允许通过猜测直接固化为业务规则，应在实际数据和运行结果中逐步确认。

## 9. V1 核心原则

- 先保证稳定采集，再增加分析；
- 先保存原始事实，再做派生判断；
- 外部插件数据作为补充来源，不作为唯一历史数据来源；
- 同一个业务概念只保留一个内部标准字段；
- 优先简单、可维护、可恢复的方案；
- V1 完成前不扩大产品边界。
