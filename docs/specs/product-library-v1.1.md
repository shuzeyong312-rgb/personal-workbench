## Problem Statement

V1 已能独立维护厂家产品、搜索、分页、逐项删除和通过 Excel 导入。产品数量增加后，逐页核价、跨页选择和逐条导入检查带来额外操作。运营人员还需要依据产品库中的批发价制作客户报价，但不能将采购成本、内部利润或计算细节泄露给客户。

V1.1 在现有产品库页面和 API 上补充价格筛选、跨页批量管理、更易扫描的导入预览，以及一次性的客户报价 Excel 生成。产品库原始资料保持不变，导出文件严格只包含客户版白名单字段。

## Solution

沿用工作台产品库入口和 V1 页面，分批交付：

1. 列表查询：参数匹配摘要、报价状态和价格范围筛选、组合筛选、后端先筛选后分页、紧凑表格和右侧快速预览。
2. 批量管理：当前页全选、同一查询结果跨页保留选择、批量永久删除及版本校验。
3. 导入预览：普通待新增行默认批量新增；优先展示错误、冲突和疑似重复，普通行用紧凑列表呈现，整批确认栏固定可见。
4. 客户报价：按已选产品、当前筛选结果或全部产品生成预览，配置报价规则、逐项人工改价，再下载不含内部成本信息的客户 Excel。

### 代表性用户流程

- **筛选与预览**：运营人员先筛出有报价且价格在区间内的产品，再输入型号或参数关键词并选择厂家；服务端对全部条件求交集后分页。点选某行打开侧边预览，复制参数、卖点或完整产品资料，不离开列表。
- **跨页批量删除**：运营人员在第 1 页勾选若干产品，翻页后继续勾选；选择栏显示跨页总数。提交前确认永久删除数量和风险。若部分记录已被他人修改或删除，只删除仍匹配原版本的记录并逐项报告；数据库写入异常时本次有效删除全部回滚。
- **大批量导入**：上传含 193 款正常产品及 8 行错误的工作簿后，先看到 8 行错误及所有冲突/疑似重复；其余 193 行默认纳入新增计划，以紧凑列表查看。固定底栏显示跨所有预览页的新增、更新、跳过和错误数量；用户确认后按 V1 原子、幂等合同提交。
- **客户报价**：选择范围，设置加价、开票报价口径、运费和取整方式；查看服务端生成的逐款报价及低于采购价、缺少采购价或最终报价等风险。可逐项手动改价，再生成客户版 Excel。任何报价参数、人工改价只作用于本次预览和导出。

## User Stories

1. 作为运营人员，我希望在列表看到命中的参数摘要，以便不打开详情也能判断搜索结果。
2. 作为运营人员，我希望按价格低于、区间或高于某值筛选，以便定位采购价范围。
3. 作为运营人员，我希望区分有报价和未报价，以便未知价格不会被误当作零价。
4. 作为运营人员，我希望价格、关键词、厂家、报价状态和排序组合使用，并在分页前完成筛选，以便结果总数和页码准确。
5. 作为运营人员，我希望用紧凑表格扫描产品，并从侧边快速预览和复制资料。
6. 作为运营人员，我希望选择当前页或跨页产品后批量删除，并在确认前看到永久删除数量和风险。
7. 作为运营人员，我希望导入时先处理错误和重复候选，同时一次确认普通新增产品。
8. 作为运营人员，我希望从已选、当前筛选结果或全部产品生成报价，并能逐项覆盖自动价格。
9. 作为运营人员，我希望客户文件只包含产品资料、最终报价和客户报价说明，避免泄露采购成本和内部计算信息。
10. 作为客户，我希望报价表明确标注待报价产品、税费/开票报价口径和运费条件，避免把报价假设误读为法定税率或整单运费承诺。

## Implementation Decisions

### 1. 复用范围与边界

| 位置 | 现状 | V1.1 方案 |
| --- | --- | --- |
| 导航与页面 | 既有 `product-library` 导航进入 `ProductLibrary` | 保持唯一入口；扩展现有页面，不新建产品库导航或全局状态系统 |
| 列表查询 | FastAPI 产品库 Router/Service 已支持五字段关键词、厂家、服务端分页和更新时间/价格排序；列表项包含完整产品字段与 version | 扩展同一列表接口的报价状态和价格条件；所有谓词进入服务端查询后再计数、排序、分页 |
| 分页与交互 | 工作台已有 `PaginationBar`；产品库导入预览有分页状态 | 复用分页样式与工作台 `PaginationBar`；按页面与既有表格控件实现勾选，不另造组件体系 |
| 导入 | V1 已保管预览凭据、差异、版本基线、决策及回执 | 只调整预览呈现与默认批量决策；不替换导入解析、重复识别、并发校验、事务或幂等引擎 |
| Excel | Backend 已固定 openpyxl 并用于模板/导入 | 在现有服务端增加报价预览和客户工作簿生成；不新增 Excel 依赖或在客户端组装客户文件 |
| 测试 | pytest + 隔离 SQLite/TestClient；Vitest；Playwright；API Mock 默认拒绝未声明接口 | 复用现有测试设施与最高可用边界，不接触正式库、采集批次或真实平台 |

产品库仍与 Competitor、Snapshot、采集任务及监控业务隔离。不得在报价流程中修改产品库字段。没有报价历史、批量操作历史或导出历史页面。

### 2. 列表筛选与预览

- 保留 V1 搜索范围：产品型号、产品名称、参数、卖点和厂家名称；不把价格备注纳入关键词搜索。活动关键词显示命中字段；命中参数时显示截断的参数片段，必要时可在侧边预览查看完整内容。
- 价格条件一次只选择一种：`below`、`above` 或 `between`。低于 X 使用 `price < X`，高于 X 使用 `price > X`，区间使用 `X <= price <= Y`。区间端点包含；单边端点不包含。金额按 V1 批发价规则解析为十进制人民币金额，范围 0～999999999.99、最多两位小数；区间缺值、负值、格式错误或 X > Y 返回明确输入错误，不默默修正。
- 报价状态为 `all`、`quoted`、`unquoted`。未知价是 NULL；明确 0.00 是已报价。价格阈值只匹配非 NULL 价格。其他条件、关键词、厂家及报价状态以 AND 组合。与区间不相容的报价状态组合返回空结果。
- 排序继承 V1 选项；价格升/降序下 NULL 均排在已报价项之后。更新时间排序以 `updated_at DESC, id DESC` 收尾，价格排序以 `id DESC` 收尾，沿用 V1 当前查询的稳定顺序。服务端先计算符合条件的总数，再对排序结果分页；切换筛选条件将页码重置到第 1 页。
- 紧凑列表沿用工作台表格规范。快速预览在右侧面板展示完整产品字段和更新时间；参数、卖点及“复制完整资料”分别有复制操作。完整资料复制默认只含产品型号、产品名称、完整参数和卖点；明确排除厂家名称、批发价、价格备注及内部计算信息。若参数或卖点命中本 Spec 定义的采购成本敏感风险词，复制前提示用户核查；用户确认后按原文复制，不自动修改原始数据。复制失败时给出可见反馈。

### 3. 跨页选择与批量删除

- 每行有选择框；“选择本页”只选择当前展示页的可操作产品。翻页和排序时保留选择；用户改变关键词、厂家、价格或报价状态时，清除旧查询的选择并显示已清除提示，防止隐藏选择集合误操作。提供显式清空选择操作。
- 批量删除请求仅携带被选中的 `id` 与列表读取时的 `version`，不得按当前筛选条件直接删除。重复 ID、非法版本或空集合拒绝请求。
- 二次确认明确写“永久删除”、精确的预期数量及产品资料将不可恢复的风险；不得只用图标或颜色表达。确认后服务端在一个短写事务内逐项比较 ID/version：相同版本删除；已不存在的记录记为 `missing`；版本已改变的记录保留并记为 `stale`。返回逐项结果及 deleted/missing/stale 计数。
- 这是允许部分失效的确定合同：有效项可以删除，其余项保留并要求刷新后重新选择。若数据库写入或提交失败，事务回滚本请求中所有有效项，响应整体失败；不出现部分已删。结果成功后从选择集合移除已删除项，失效项仍保留选择并显示原因，用户可清除或刷新。
- 只新增一个产品库批量删除 API；复用 V1 单项版本语义，不增加审计表或监控任务。

### 4. 导入预览交互

- V1 的文件校验、行分类、重复识别、人工确认更新、空值保留、预览过期、并发基线、事务回滚及幂等回执原样继承。
- `new` 正常产品默认 `insert`；已有无变化产品、冲突、疑似重复仍按 V1 默认 `skip`，更新仍需逐行明确确认。错误行不能选择新增或更新。
- 预览优先顺序为错误、冲突、疑似重复、普通待新增/已有产品；同类保持 Excel 行号顺序。普通行以紧凑行展示型号、名称及关键信息，默认不展开全字段差异；用户可展开查看 V1 的 old/incoming/effective 差异。问题行默认展示错误原因、候选和必要差异。
- 计划新增/更新/跳过/错误数必须根据整批全部行和当前决策计算，不能只统计当前页。底部操作栏在预览滚动和分页时始终可见；显示整批计数及有效期，并提供确认、查询原回执等 V1 状态操作。无可写操作、过期、stale、网络不确定状态继续遵守 V1 禁用和恢复规则。

### 5. 客户报价范围与计算

- 导出范围：`selected` 使用跨页选择集合；`filtered` 使用当前全部筛选命中项（不限当前页）；`all` 使用产品库全部产品。服务端将范围解析为固定顺序的产品 ID/version 列表。前端修改范围或报价规则时必须使当前预览失效并重新请求预览。提交导出时若产品已删除或 version 改变，拒绝生成并返回受影响产品；前端保留用户输入和手动报价，刷新受影响项并要求重新查看预览后再导出，不静默混入新产品或使用旧数据。
- 未报价产品默认排除。用户可切换为保留未报价项；这些行需在预览中明确标为“待报价”，客户 Excel 最终报价列显示“待报价”。用户可为其手动补价后转为普通报价行。没有有效报价的行不参与加价百分比计算，也不与 NULL 作数值比较。
- 所有金额使用服务端 `Decimal` 计算，不使用二进制浮点。计算顺序固定：采购价 → 百分比/固定金额加价 → 开票报价调整（如选用）→ 单件运费（如选用）→ 最终取整。中间步骤只做精确 Decimal 运算，不量化到分、不提前舍入。默认最终两位小数使用 `ROUND_HALF_UP`；整数元选项使用数学 ceiling，恰为整数不再加一元。
- 单个产品最终报价上限为人民币 `999999999.99`，与 V1 产品价格上限一致。自动计算或人工报价经最终取整后超过上限时，不截断、不回绕、不导出该次报价；预览该行显示超限错误，用户必须调整规则、改价或移出范围后才可导出。金额边界校验在最终舍入后执行，任何中间计算溢出或非有限数也按错误处理。
- 加价选项：不加价、按百分比增加前一步金额、每件增加固定金额。百分比按百分点录入（例如 10 表示 10%），范围 0～1000%，最多两位小数。固定金额以人民币元录入，必须非负且最多两位小数。
- 税费/开票口径选项：`不含税` 不作税费计算，默认客户说明为“以上报价为未税单价，税费另计。”；`报价已含税` 不作额外计算，默认说明为“以上报价为含税单价。”；`按指定开票报价调整比例加价` 在加价后金额上按用户给定比例增加，默认说明为“以上报价按指定开票报价口径调整，具体开票内容及适用条件以双方确认为准。” 该比例仅为本次商业报价参数，不称为法定税率、不推断税额，也不保证特定发票资格或税务结果。不得在客户说明中展示调整比例或计算值。
- 开票报价调整比例按百分点录入，范围 0～1000%，最多两位小数；仅在对应模式下应用。
- 运费选项：`运费另计` 不增加单价，默认客户说明为“运费另计，金额以订单确认为准。”；`报价已含运费` 不作额外增加，默认说明为“以上报价已含运费。”；`每件固定增加运费` 将固定金额加到每件报价，默认说明为“以上报价已计入单件运费，整单实际费用以订单确认为准。” 固定运费以人民币元录入，必须非负且最多两位小数；仅在对应模式下应用。不得把单件运费描述成整单总额或另作实际物流费用承诺。
- 税费/开票说明与运费说明按选择组合生成，不展示用于计算的比例或内部金额。上述文案是客户报价口径说明，不增加税务、发票资格或整单物流保证。
- 低于采购成本按最终报价与结构化批发价比较；最终报价低于采购价时提示风险，不自动阻止导出。缺少采购价的手动补价行无法判定成本风险，应明确提示“无法核对成本”。
- 预览中逐项手动最终报价覆盖自动计算值。改动统一报价规则只重算自动行，不覆盖人工覆盖行；每行可显式恢复自动计算。人工输入为非负人民币金额，最多两位小数，且不超过最终报价上限。低于成本、采购价缺失、最终报价缺失等风险逐项展示。
- 报价调整和手动覆盖仅存于当前导出预览状态，不写回 `library_products`，不建立报价历史。

### 6. 客户 Excel 隔离与说明

- 客户工作簿只包含一个可见工作表；列白名单固定为产品型号、产品名称、完整参数、卖点、最终报价、报价说明。默认不包含厂家。
- 结构化批发价（采购成本）绝不进入客户 Excel，包括任何单元格、工作表、隐藏内容、批注、属性、文件名或其他元数据；价格备注也不导出。内部利润、加价类型/比例、开票调整比例、内部运费成本、version、产品 ID、隐藏列及任何计算公式均不得输出。服务端只用允许的客户字段构造全新工作簿，不复制产品表或模板工作簿；最终价格写为计算后的常量值。待报价使用明确文本“待报价”。
- 产品名称、参数和卖点可能含供应商采购价或内部交易条件。客户报价预览扫描即将输出的产品型号、名称、参数和卖点文本中的风险词（至少包括：成本、采购价、进货价、拿货价、供货价、底价、批发价、内部价、利润、加价率、开票调整、运费成本），标出命中产品、字段和原文片段。用户必须逐项核查每个命中产品并明确确认，且确认已核对全部客户可见产品文本后才能导出；未命中风险词不代表系统保证文本安全。导出请求携带核查确认，服务端在版本校验后重新扫描并校验确认覆盖全部命中项。检查只提示，不自动删除、遮蔽或改写产品原始资料。
- 用户商品文本按字面文本写入，不能被 Excel 当作公式执行。工作簿不包含隐藏工作表/列/行。报价说明仅反映所选税费/开票和运费条件，不暴露用于计算的数值比例、采购价或内部运费。
- 不自动导出 V1 的 `price_note`，因为其内容为厂家价格条件，可能含内部采购信息；客户可见说明只由本次报价口径生成。
- 报价预览由服务端按 Decimal 规则核算，返回固定有序的产品 ID/version 集合、规范化报价规则、计算结果及该集合/规则的 SHA-256 一致性摘要（对有序 ID/version 与规范化规则的 UTF-8 canonical JSON 求摘要，不持久化）。下载请求必须提交同一完整集合、相同顺序和版本、报价规则、摘要及人工覆盖。服务端重算摘要，重新读取并校验所有产品仍存在且 version 全部匹配，再自行重算自动报价并生成 xlsx。摘要不匹配、任何产品缺失/版本变化、集合增删/重排或规则变化时，拒绝整份导出、不生成部分文件，并返回需刷新的产品/预览原因；前端保留用户输入和手动报价供重新核对。摘要用于检查预览/导出请求一致性，不作授权凭证；服务端不信任客户端提交的自动价格或风险扫描结果。
- 完整资料复制字段白名单为产品型号、产品名称、完整参数和卖点；不包含厂家名称、批发价、价格备注、利润、加价/开票调整比例、运费成本等内部计算信息。参数或卖点命中既有敏感风险词时，复制前提示用户核查；确认后保留原文，不自动修改源数据。预览与文件生成均不保存报价数据或改变产品版本；不增加数据库表或 Alembic migration。

### 7. 最小 API 变化

在现有产品库 Router/Service 内：

1. 扩展 `GET /api/product-library/products`：增加 `price_status=all|quoted|unquoted`、`price_mode=below|above|between` 及对应十进制边界参数；原有 q、manufacturer、sort、page、page_size 继续兼容。
2. 增加 `POST /api/product-library/products/batch-delete`：接收 `{items:[{id,version}]}` 并返回逐项部分失效结果。
3. 增加 `POST /api/product-library/customer-quotations/preview` 和 `POST /api/product-library/customer-quotations/export`。预览请求包含范围、选定 ID 或当前筛选条件、报价规则及是否保留未报价项；预览返回解析后的产品 ID/version、规范化规则摘要、自动最终价和风险。导出请求提交相同快照、规则摘要、人工覆盖及客户文本核查确认；后端重新校验摘要、风险词、产品版本并核算后按客户字段白名单生成文件。

查询参数和请求字段需由服务端校验，错误沿用产品库 API 错误格式。金额按十进制字符串接收；比例只接受 0～1000%、最多两位小数；固定加价、单件运费、人工报价非负且最多两位小数；最终报价不得超过 999999999.99。无持久化状态变化，不迁移数据库，不触碰 V1 导入凭据合同。

## Testing Decisions

好测试通过既有 pytest/TestClient、Vitest 和 Playwright 接缝观察用户可见结果及数据库最终状态，不锁定内部函数调用或组件实现。所有测试使用隔离 SQLite、受控 API Mock 和临时工作簿；客户 Excel 测试须重新打开生成文件并检查所有工作表、单元格和公式，而非只断言下载成功。

## Out of Scope

- 产品库图片、SKU、附件、库存、订单、供应商档案和价格历史。
- 订单级运费分摊、客户/税务资料管理、法定税率推断、自动开票或税务承诺。
- 报价模板设计器、报价单历史、批量操作审计中心、通用导出平台。
- 自动采购价/市场价同步、利润目标推荐、自动定价或报价与竞品监控联动。
- 重新设计工作台 UI System、迁移 V1 导入引擎或大范围重构产品库。
