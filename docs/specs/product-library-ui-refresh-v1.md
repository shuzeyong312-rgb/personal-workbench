# 产品库完整 UI/UX 升级 V1

2026-10-20。视觉变更；业务权威仍为 product-library-v1 / v1.1。用户授权同任务设计审查、实施与验收，不 Commit/Push。

## 设计与范围

延续 ui-system V1.3、当前首页的中性灰/白色/石墨/操作蓝及本地字体。列表使用 List Reference；阅读抽屉使用 Detail Reference。页面主操作为手动新增，导入为次操作，报价独立呈现，模板移至导入任务内。搜索占更大宽度，组合筛选和选择反馈分层；保留全部现有过滤及排序。

新增/编辑使用宽对话框，基本信息、客户资料、内部价格三个 fieldset；桌面双列、窄屏单列。标题与底部操作固定，正文独立滚动，未保存编辑关闭时确认。详情抽屉以产品身份、客户可复制资料、内部价格、时间组织，复制反馈不移动焦点。导入以实际上传/预览/回执三阶段显示；报价以范围、价格规则、客户文本复核组织，全部风险和人工覆盖继续可达。危险删除采用紧凑确认框。

所有按钮、输入、select、文件选择、分页、details、状态和焦点需统一。高频表单/抽屉即时打开，不增加入场等待；仅按钮颜色提供 150ms 状态过渡，reduced-motion 关闭。所有 CSS 作用域限定 library-page / library-dialog，不改全局组件。

## 不变量与影响范围

不修改 backend、API、数据库、模型、七字段含义、校验、报价计算/精度/上限、文件格式/大小规则、Excel 白名单/公式安全、复制内容和敏感确认、id/version 快照、跨页/批删语义。新增关闭确认仅防止丢弃未保存内容，不新增自动保存。

实现仅涉及 ProductLibrary.tsx / ProductQuotation.tsx / ProductLibrary.css、对应测试和文档。LibraryDialog 仅被产品库编辑/导入/详情/删除和 ProductQuotation 使用；PaginationBar 不修改。保留原请求和所有状态机，重组 JSX 不重写业务函数。无依赖和新路由。

## Gate

实施前只读 Spec Review 核查范围/状态/业务不变量；实施后 Chromium 受控 API fixture 截图 before/after，补充键盘、关闭确认、窄屏检查。运行 typecheck/build/Vitest、产品库及 Shell E2E、隔离 backend 产品库 pytest（含计算和 Excel 安全），diff --check；独立只读 Review 与 Final Gate。受控数据不代表正式库或真实厂家验收，不触及正式数据库。
