# 产品库商品身份规则

2026-10-29：产品库 V2（Issue #8）覆盖原“厂家+型号+名称”运行期规则。完整合同见 [产品库 V2](product-library-v2.md) 第 3.3、4.7、6、9 节。

## 当前规则

- 产品 ID 保持稳定，version 为并发令牌。身份为规范化后的 **型号+名称**，资料来源公司不参与匹配。空型号只匹配空型号同名产品；与有型号同名产品独立。
- 型号、名称去首尾空白并统一换行；大小写、全半角、标点和规格原文保持精确 BINARY 比较，不做模糊归并。
- 数据库索引为 `uq_library_products_model_name(model,name) WHERE model IS NOT NULL` 和 `uq_library_products_null_model_name(name) WHERE model IS NULL`。
- 旧 manufacturer_name 保留为首录资料公司兼容字段；多家公司提供的资料通过来源记录关联到同一产品，不能据此推定实际生产厂家。
- 同型号异名、同名异型号可以独立新增；同身份跨公司不得新建第二个产品。导入复用主产品时，默认保留主字段和默认价，新增来源及价格需要明确决策。

## 导入与并发

新预览和回执记录 `identity_rule_version=4`；V2 模板另记 `template_version=2`。旧 ready 读取/确认均返回 409 preview_rule_changed，要求重新预览；缺版本、版本 2/3 的 committed 回执仍按原决策摘要幂等重放。

预览基线覆盖本批全部型号+名称的存在/不存在，以及产品和关联资料快照，不按厂家分区。确认在 BEGIN IMMEDIATE 后重验基线及目标版本，写入与回执同事务提交。其他来源的并发创建或关联变动也会使预览失效。

V2 主产品重复身份组必须整体跳过或修正文件；关联行按工作表、行号、类型和临时ID定位。use_existing 保留主字段但处理关联资料；skip_product 放弃整组。详细动作、依赖和参数冲突规则以 V2 Spec 第 6 节为准。

- 历史 revision `20261020_17` 保留不改，记录原厂家公司身份规则的演进。

- `20261029_21` 增加关联资料与参数字段，回填 legacy 来源和已有默认批发价，不重写旧产品 ID/version、原字段或 committed 回执。
