# 客户报价 Excel 升级合同（2026-10-21）

本轮用户需求为授权来源；局部覆盖旧 Spec 中报价展示列与固定说明规则，原算法、范围、版本、文本安全与隔离规则继续有效。无需 Schema、依赖、持久化或正式库写入。

- 统一 MOQ：本次所有产品共用，必填正整数 1～999999999，初始 1，可编辑，写入每行客户 Excel；不改变价格算法或产品库。
- 自定义说明：初始空白，可留空；最多 2000 字符，多行原文保留（CRLF/CR 规范化为 LF），禁止 Excel 非法字符。不自动生成税运费说明；界面另展示内部税运费口径供核对。提示用户自行写明条件。
- 说明也扫描既有敏感词；命中需显式核查确认；全部客户文本总确认仍必需。写入字面字符串，公式前缀不执行。
- 预览返回原始批发价，仅内部显示。表格三列：型号/名称、原始报价、可直接编辑的最终报价。风险、错误留在对应行，客户文本展开核查，保留恢复自动报价。
- 修改规则、MOQ、说明或人工价格均使预览失效并清空核查确认；重算后才能下载。摘要覆盖有序产品/version、规则、规范化人工覆盖、MOQ 与说明，服务端再次校验并计算。
- Excel 七列：产品型号、产品名称、完整参数、卖点、最终报价、MOQ、报价说明。禁止自动写入原始价格、内部备注、厂家、计算比例、ID/version、隐藏内容、公式。
- 配置在生成预览后可折叠；报价表保留搜索/风险筛选/20行分页；底部重算、确认、下载保持可用；单一正文纵向滚动，窄屏重排。

验收：定向后端（边界、篡改、原库不变、实际xlsx隔离）、前端测试/构建，真实Chromium连接临时SQLite完整配置→重算→文本核查→下载→解析Excel；桌面/窄屏/分页/版本变化检查。独立Standards/Spec Review→Fix→Final Gate；无Commit/Push。
