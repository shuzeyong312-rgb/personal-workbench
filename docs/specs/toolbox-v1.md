# 常用工具箱 V1（按独立 Spec Review 裁决修订）

## 目标与基线

依据 [Issue #2](https://github.com/shuzeyong312-rgb/personal-workbench/issues/2)，在工作工具下提供网站入口和浏览器本地图片处理，不修改产品库或其他业务。[已确认的 HTML 原型](../prototypes/toolbox-v1/toolbox_v1_prototype.html) 是视觉和交互参考，不是生产代码、持久数据或接口合同；页面遵守 `docs/ui-system.md` 和现有 Shell。风险级别 L：新增持久数据与迁移。源码基线 `e2ea2f47e735a42fd82762c12145546e583e1f88`（相对 `8188bd2803986041767ddac6c031f02fbd6d0311` 仅增加原型）：导航在 `frontend/src/App.tsx`，后端通过独立 router 和 SQLAlchemy Session 接入；Alembic 单 head 为 `20261023_18`，前端尚无 ZIP 依赖。

原型呈现搜索筛选、收藏及工具卡片，网站编辑弹窗，图片工作台的队列、参数、前后预览和下载。沿用其信息结构与已确认方向，Shell 尺寸、移动导航、键盘访问和视觉 token 以现有系统规范为准。原型的内存数组、自制 ZIP、文件类型判断及处理代码不作为生产实现或验证证据。

## 目录与持久化

- 新增一个 SQLite 目录表和后续 Alembic revision，预置两个内置工具和收藏的 iLovePDF。内置项以稳定 key 与前端注册表对应，用户不能编辑、删除或注入路由；收藏属于持久数据，升级不得覆盖用户选择。未来内置项通过迁移按 key 安全增加。
- 目录支持名称、描述、分类搜索及全部、收藏、内置、外部筛选；收藏区与目录均可打开工具。外链可增删改和收藏；删除仅删除入口。新标签打开使用 `noopener,noreferrer`，不抓取或代理外站。
- 服务端校验非空名称、长度、重复名称及绝对 HTTP(S) URL；拒绝其他协议、无主机及无效 URL。内置记录的修改和删除请求必须拒绝，收藏接口只更新收藏状态。
- 名称去除首尾空白后 1–100 字符，分类最多 50、描述最多 200、URL 最多 2048 字符；名称以 Unicode casefold 后全目录唯一，使用持久化规范化键和数据库唯一约束，不依赖 SQLite NOCASE。外链的完整规范化 URL 唯一，编辑排除自身；路径大小写不得盲目折叠。重复返回 409 并提示具体原因，数据库约束兜底并发。URL 必须有主机，拒绝凭据、控制字符和非 HTTP(S) 协议。校验失败使用统一 `{code, message}`，资源不存在返回 404。
- 网址规范化统一协议和 IDNA 主机大小写、默认端口、空路径及路径点段，并对非 ASCII 路径编码；保留路径大小写、查询和片段。不得以宽松解析允许反斜杠或凭据。
- 页面刷新或服务重启后保留外链和收藏；迁移在隔离数据库验证既有数据不变、预置不重复和升级路径。恢复采用升级前备份，不对含后续写入的数据直接降级。

## 图片处理

- 两个内置工具共用队列、处理及结果，文件从选择到下载都在浏览器本地，不上传服务端或第三方。允许 JPG/JPEG、PNG、WebP，实际解码验证；单批最多 12 张、每张最多 20 MiB、源图最多 45MP。逐文件处理并保留失败原因，释放临时 object URL。
- 压缩提供智能、高压缩率和目标 KB；清楚标明输出格式。目标是尽力而为，未达目标显示实际大小和原因；PNG 不保证显著缩小，结果变大时提示并允许保留原图，不伪造压缩率。编码格式不受支持时报告错误，不偷偷换格式。
- 尺寸提供 800×800、1000×1000 和自定义正整数目标尺寸；默认等比完整保留并留白，另一模式等比居中铺满裁切，不拉伸。白色填充为默认；透明和 JPEG 白底行为明确展示。目标宽高各不超过 8192 像素，且乘积不超过 45MP；检测实际解码、Canvas 分配和编码失败，不把该上限视为所有设备可用的保证，不跨批同时创建高像素 Canvas。
- 设置或队列改变时使当前异步处理结果失效，清理 Blob/Object URL，不可写回或下载迟到结果；逐条保留失败原因。ZIP 对同名源图使用确定性无冲突名称，扩展名与实际编码一致，并可由标准工具解压。
- 批量保留的结果和缩略预览总计上限为 64 MiB，超出时保留已成功项目并逐条提示分批处理。大图预览使用缩小副本，下载仍为原始处理尺寸；ZIP 以分块方式打包，设置或队列变化时取消旧打包。尺寸头检查在完整解码之前执行；实际设备仍可能因内存不足而失败，必须显示失败原因。
- 展示源图和结果的真实尺寸、体积与预览；支持移除、清空、单图下载及仅成功结果的无冲突命名 ZIP。参数改变即清除旧结果并禁止下载旧结果。处理后文件不覆盖原图；告知 Canvas 不保证保留 EXIF/ICC。

## 失败、验证与非目标

加载、保存、解码、超限、部分失败及格式不支持均有明确反馈；失败不得清空其他项。支持键盘操作、移动导航及 1440/1024/390 宽度下关键操作可见。

隔离 pytest 覆盖迁移、预置、CRUD、内置保护、协议限制、重复、收藏持久化和错误；Vitest 覆盖全局搜索入口、图片处理和 ZIP 等逻辑。必要时在真实浏览器人工验收导航、CRUD、刷新、上传、不同长宽比、透明 PNG、照片、压缩、等比留白、裁切、失败和可打开 ZIP。运行受影响回归、类型检查、构建、`git diff --check`；不使用生产库、真实采集或 `dev.ps1`，不维护前端 Playwright E2E。

不做 PDF 解析、远程上传、AI 图片、产品库图片、账号同步、任意脚本、无关页面改版。实现与同步后仍需固定 SHA 独立代码 Review 和用户操作验收，方可决定合并；本任务不合并、不部署。
