# 首页：精密工作舱

本次用户需求授权的首页局部升级，延续 `docs/ui-system.md` 的浅色体系；旧首页 Spec 的业务合同仍有效。仅首页允许少量几何线性图形，替代旧版禁止所有装饰的局部约束。不修改 Shell、业务页面、API、数据库、依赖，不 Commit/Push。

## 设计合同

场景为日常高频桌面操作，模式为 Operate。保持画布 #f3f4f6、白表面 #ffffff、石墨 #20242c、次级文字 #626b78、边线 #dde1e6、操作蓝 #2563eb 和现有本地中文字体。标题最多 32px，未来感来自几何模块的空间关系、细连接线、精确切分和清晰的操作反馈，不使用霓虹、光晕、模拟仪表、虚构指标、营销文案。

首屏以“首页”及既有引导语建立身份；右侧抽象资料模块与情报模块的构型图是唯一主要视觉记忆点，纯装饰，不表达资料库与监控系统已经自动同步。下方不等宽工作区突出竞品监控主任务和产品库资料任务，保留全部真实入口。设置作为独立辅助行；四项后续工具静态展示，明确规划中且不可操作。

交互仅由用户触发：hover 时边线/底色反馈及箭头 2px 位移，按下时底色加深；150–180ms ease-out；不做入场、循环、闪烁或指针跟随。触屏不依赖 hover；reduced-motion 移除所有首页过渡和位移；键盘焦点保持可见。

## 验收与 Gate

- Spec Review：审核真实能力、入口完整性、与既有体系衔接和本次局部例外。
- Implementation：仅 HomePage、首页 CSS 与必要测试/文档；复用 NavIcon、现有按钮和导航回调。无新增请求和数据逻辑。
- Chromium：同一受控环境的前后 1440px / 390px 截图；另验 1280px、760/761px、375px、320px、横屏和 200% 字体；无横向溢出；完整键盘及减弱动效。
- Regression：Vitest、TypeScript/build、首页/Shell/导航及相邻业务布局 Playwright；验证首页全部七项入口并明确没有新增 API。
- 独立只读 Code Review / 视觉审查 / Final Gate：检查局部 diff、真实截图及结果，修复必须修复项后交付。

不采用：常规等权功能卡片阵列（缺乏优先级）；整页深色 HUD（与现有浅色系统割裂）；数据型大屏（与竞品监控重复并引入非必要请求）。

2026-10-21 用户追加：首页桌面一屏展示。通过首页纵向间距和图形尺寸适配，在1920×911、1440×900、1366×768、1280×720验证内容区及侧栏均无纵向溢出；不隐藏滚动条或裁剪内容。较矮桌面窗口仅首页使用紧凑导航，业务页不受影响；窄屏/极端窗口/文字放大保留自然滚动以保证可访问性。
