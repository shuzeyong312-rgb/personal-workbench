# 工作台整体体验升级 V1

范围：首页、App Shell、全局导航；不修改业务页面内部、API、数据模型、采集逻辑或依赖。不自动 Commit/Push。基线工作区干净。

## 产品与设计判断

首页当前只是占位页。已启用的产品库负责整理商品资料，竞品监控负责观察变化和查证；AI智能助手、全网比价、自动询价、自动上架只有占位页面。首页应帮助选择任务，而非重复监控大屏数据。

比较三种方案：数据汇总会重复大屏且引入不必要请求；等权工具卡片会把规划功能伪装为可用；采用任务入口工作台，突出两项真实能力，以明确任务描述和直接导航缩短路径。

延续 UI System V1.3：#f3f4f6 画布、#ffffff 表面、#20242c 石墨、#626b78 辅助文字、#dde1e6 边线、#2563eb 操作蓝。沿用本地中文字体栈，不加载字体。首页以标题、两种不同职责的工作区域、任务行和安静的规划清单组织；不使用 KPI、模拟活动、装饰图表、渐变或等权图标卡片阵列。

## 行为合同

- 首页保留“首页”页面身份，展示产品库入口、竞品监控大屏入口及我方商品、竞品列表、竞品分组、采集记录的真实导航。没有添加或采集捷径，相关操作仍在大屏。
- 规划工具在导航中明确标记“规划中”，保留已有占位路由；首页规划清单不伪装成可执行功能。
- 导航区分首页、已启用工作工具、规划工具、系统设置。保留竞品模块展开状态和所有原有页面标识。
- 全局面包屑提供返回首页与模块总览的操作。键盘可跳至主内容。
- 桌面导航常驻；窄屏使用原生非模态展开导航，关闭时不留下可聚焦隐藏控件；选择页面后收起，Escape 关闭并返回触发按钮；不遮挡正文。
- 主内容原有宽度与业务组件 Token 保持。新增样式限定首页和 Shell，避免重设全局表格、按钮或卡片。
- 高频导航无入场动画；仅 hover/focus、折叠箭头提供短反馈，尊重 reduced-motion。
- 首页无数据请求，无 Loading/Empty/Error 数据状态；数据页原有状态继续有效。

## 验收

1. 首页所有入口到达正确业务页，无伪造数据与无效主操作。
2. 桌面、窄屏布局无首页/Shell 横向溢出，键盘焦点可见，导航可展开/关闭。
3. 已有列表、详情、组分析、采集记录、产品库、设置及占位页可访问。
4. Vitest、TypeScript/build、Playwright 回归通过；实际 Chromium 前后截图与视觉复查。
5. 独立只读 Spec Review、Code Review、Final Gate；已有业务页内部无独立改版，后端无差异。
