# 1688 经营指标 V1.1 前端体验规则

本增量只调整 Group Detail 的经营指标展示与表格排序，以及右侧商品速览；不修改已冻结的 V1 集成 Spec、数据合同、Backend 排名资格或采集行为。

- 指标表格只显示最近一次尝试的原始值或状态。`observed` 使用本次原文，`placeholder` 保留原文（包括 `-`），`loading`、`source_unavailable`、`read_failed` 和 `not_attempted` 分别显示独立状态；不得用 `latest_valid` 填充当前表格值。
- 表格排序仅解析当前显示的有效观察值。`-`、空值、状态文案及不可解析原文在升序和降序中均置底；相同数值按商品 ID 升序稳定排列。
- 上架时间按可解析日期排序；评论数、好评率、揽收率按可解析数值排序。成交类原文（如 `100+`、`70+`、`<10`）保持原文，按显示边界排序；边界相同时按 `<`、无标识精确值、`>`、`+` 的展示档位顺序排序，降序反转。组合标记（如 `<10+`）属于无效格式并置底。可能重叠的成交档位只表示展示档位顺序，不表示精确销量或真实竞争排名。
- 三个对比视图中的店铺名称复用 API 的 Offer URL；仅有效 HTTP/HTTPS URL 可成为新标签页链接，并使用 `noopener noreferrer`。缺失或异常 URL 显示普通文本；链接点击不改变当前行选中状态。
- 首次点击上架时间按最近日期优先，其他数值和档位按较大值优先；再次点击切换方向。表头保留排序箭头、高亮、键盘触发和 `aria-sort`。
- 经营表现、口碑履约的每个已接入指标列可点表头排序；竞争总览中已有经营指标列同样可排序。原有 Backend 价格、MOQ、SKU、库存位置排序保持不变。
- Group Detail 速览仅呈现店铺/我方标识、两行商品名、Offer ID、报价/MOQ/SKU/完整库存、商品与监控状态、最近有效基础快照时间、可用的既有真实位置及详情入口。完整指标来源、采集时间、最近尝试和历史有效值继续由独立商品详情展示。
