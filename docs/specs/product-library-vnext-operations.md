# 产品库 VNext 操作修订：范围与身份规则审查

日期：2026-10-20。依据本轮用户需求；历史 V1/V1.1 与 UI Refresh Spec 原样保留。本轮代码不 Commit/Push，不执行正式迁移或数据清理。

## 通过实施的范围

1. 价格输入草稿与已生效条件分开；仅完整有效金额更新查询。旧查询使用 AbortController 防止覆盖。金额范围0～999999999.99、最多两位小数，区间含端点；条件切换清除不相关边界，草稿无效时说明仍使用上次有效条件。
2. Dialog 仅处理自身 cancel；文件 input 的冒泡 cancel 不关闭导入窗口。没有新文件时保留原 File 与厂家、表单状态，Escape 仍可明确关闭窗口。
3. 清空筛选一次恢复关键词、厂家、报价状态、价格模式/边界与默认排序、第一页；按现有契约清除跨页选择，保护异步查询。
4. 导入审核20行分页，型号/名称搜索，真实审核分类过滤；可选参数/卖点缺失为独立提醒而非非法。计划操作与审核状态分列，冲突默认跳过且标记待人工确认。正常新增默认整批新增，可整批跳过/恢复新增；不批量确认疑似或冲突。详情展开保留全部六字段差异、候选和错误。决策以原Excel行号保留，过滤不改变提交集合。
5. 结果使用 committed 回执，20行分页、真实结果筛选；新回执附源型号/名称/错误，旧回执缺失字段显示未提供，不反查当前产品冒充历史输入。网络未知先查询原import_id；已知数据库失败仍显示全部回滚，允许原请求重试；不显示成功写入。
6. 报价明细20行分页，搜索型号/名称与风险、错误、人工改价、待核查过滤。服务器同时返回 automatic_price 与 final_price；前端不复制Decimal公式。改价/规则修改即时失效并提示待核算，复核后下载；恢复自动会清除本次覆盖。保留全部客户文本、风险逐项确认和总确认，版本变化刷新原快照。

## 设计决定

沿用 docs/ui-system.md 的 List Reference：灰白表面、石墨文字、操作蓝、原中文字体与13px正文。价格模式与必要金额为一个可重排控件组。审核与报价以紧凑表行横向核查，长文本只在对应行展开。表格内部滚动、表头固定、底部操作保留；390px窄屏允许明细横向滚动，窗口本身不溢出。不引入依赖、动画库、独立卡片或新字体。

## 第5项：身份规则独立 Spec Review — BLOCKED，保留旧规则

当前正式库只读快照：backend/data/personal_workbench.db，revision 20261018_16；193产品、1厂家、0空型号；同厂家同名不同型号34组；同型号异名0组是旧约束的必然结果，不能证明不存在此业务。导入回执3个committed、2个ready。未迁移、未写库。

现有模型索引uq_library_products_manufacturer_model为(厂家,型号) WHERE 型号非空。手动同型号一律拒绝；文件内非空同型号全部非法，无型号同名全部非法；文件内不同型号同名可判new。库内同型号同名称为existing，同型号异名为conflict，仅可更新/跳过。上述规则不符合新身份需求，本轮不声称已实现。

比较：

| 方向 | 成本与风险 | 结论 |
| --- | --- | --- |
| 仅换厂家+型号+名称唯一键 | 索引简单，但CRUD、文件内分类、更新目标、旧预览仍按旧规则 | 不足以实现 |
| 只靠精确匹配+人工决策并去掉唯一性 | 全部并发入口必须一致，失去数据库精确重复保护 | 不推荐 |
| 非空型号三字段部分唯一键+精确匹配+人工冲突 | 可满足业务；必须同步所有入口和凭据版本 | 推荐未来完整方案 |

独立审查：identity_review（只读）。关键阻塞：

- 当前ready凭据只有产品集合baseline，没有身份规则版本；算法变化而数据不变时，旧预览仍可能提交。需要版本校验并拒绝旧ready，保留committed幂等查询。
- 新规则允许同型号多个候选，不能继续 exact[0]；精确匹配确定唯一目标，否则用户必须确认目标id/version，纳入决策摘要与并发检查。
- 旧索引重建会被新规则合法数据阻塞。降级必须预检并拒绝；不能自动删数据/合并。正式回滚需升级前一致性备份并先导出升级后新增资料。
- 报价与复制依赖产品id/version与字段，保留ID即可；名称只保留既有首尾空白/换行规范化，不删除规格、颜色、尺寸、技术参数，不引入模糊合并。

未来迁移门禁：独立Spec Review后备份；隔离副本升级前后比较全部产品字段、ID/version、金额与回执；验证各种身份组合、文件内/正式库重复、并发/幂等；演练降级拒绝与快照恢复。正式迁移另需明确授权。本轮没有创建迁移或改模型，因而不存在迁移前后对比或回滚执行证据。

界面明确当前同厂家同型号只能保存一款，异名确属独立产品暂不可分别新增。其余六项与该Schema变更独立。
